# Footprint Mappa Report Builder

## Project Goal
Web app that generates professional PDF carbon footprint reports for products (PCF)
and organizations (OCF) by uploading a CSV. Output must be client-ready, similar
to a consulting report style (professional, clean, data-driven).

## Stack — STRICTLY FOLLOW THIS
- Next.js 16, App Router, JavaScript/JSX — NO TypeScript ever
- Tailwind CSS v4
- shadcn/ui (Nova preset, Radix UI, Lucide icons)
- PDF generation: @react-pdf/renderer
- CSV parsing: papaparse
- Charts in PDF: recharts (render to canvas, then embed as image in PDF)
- Deploy: Vercel

## Project Structure
- Pages in src/app/
- Reusable UI components in src/components/
- PDF report templates in src/components/pdf/
- Data parsing and transformation in src/lib/

## Report Types

### PCF Report (ISO 14067) — Product Carbon Footprint
Lifecycle phases (map CSV columns to these):
1. Materials (total_materials) → subcategories: 1_1, 1_2, 1_3
2. Manufacturing (total_manufacturing) → subcategories: 2_1, 2_2, 2_3, 2_4
3. Transport (total_transport) → subcategories: 3_1 to 3_5
4. Distribution (total_distribution) → subcategory: 4_1
5. Use (total_use) → subcategories: 5_1, 5_2, 5_3
6. End of Life (total_end_of_life) → subcategories: 6_1, 6_2, 6_3
Unit: kg CO2e per functional unit

### OCF Report (ISO 14064) — Organization Carbon Footprint
GHG Protocol scopes:
- Scope 1 (total_scope_1): direct emissions → subcategories: scope_1_1 to scope_1_4
- Scope 2 (total_scope_2): purchased electricity → subcategories: scope_2_1
- Scope 3 (total_scope_3): value chain → subcategories: scope_3_1 to scope_3_15
Unit: kg CO2e per year

## PDF Report Structure (both types)
1. Cover page — report title, type (PCF/OCF), standard (ISO 14067 / ISO 14064),
   company name (editable field), year, generated by "Footprint Mappa"
2. Executive summary — total emissions, dominant phase/scope, key insight sentence
3. Results table — all products or entities with phase/scope breakdown
4. Bar chart — emissions by phase or by scope (visual)
5. Subcategory detail table — granular breakdown
6. Footer on every page — "Confidential · Footprint Mappa · [year]"

## UI Flow
1. Home page: choose PCF or OCF (two cards)
2. Upload page: CSV upload + company name input field + year selector
3. Preview page: parsed data shown in a table before generating PDF
4. PDF is generated client-side and downloaded directly

## Rules
- All UI text and labels in English
- NO TypeScript under any circumstance
- Always use shadcn/ui components (Button, Card, Input, Table, Select...)
- PDF must look professional: white background, green accent color (#16a34a),
  clean typography, page numbers
- Never hardcode data — everything comes from the uploaded CSV

## Brand Guidelines (Footprint Mappa)

### Colors
- Primary gradient: left #fdc2d8 (pink) → #fca65e (orange) → #ff7983 (coral) → #041282 (navy)
- Backgrounds: black (#000000) or white (#ffffff) only
- Text: black on white backgrounds, white on black backgrounds
- Never use solid brand colors directly — they appear only in the gradient

### Gradient usage
- Use the gradient as accent element (headers, dividers, cover page strip)
- CSS: background: linear-gradient(to right, #fdc2d8, #fca65e, #ff7983, #041282)
- Can be used as full background only if it does not affect text legibility

### Typography
- Font: Inter (already configured in layout.js via next/font/google)
- Weights: Regular for body/titles/subtitles, Bold for key highlights only
- No decorative or display fonts

### UI style
- Clean, minimal, professional
- White background for the web app
- Gradient strip used as accent on cards and page headers
- Black background acceptable for hero/cover sections
