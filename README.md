# FootprintMappaReportBuilder

Esto es una prueba de nivel de una semana para la empresa footprint Mappa, con el objetivo de crear un generador de documentos PDF que, introduciendole un csv de los productos de una empresa, sea capaz de resumir y resolver sus emisiones de huella de carbono.
